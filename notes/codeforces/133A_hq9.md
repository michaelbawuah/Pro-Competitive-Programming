# HQ9+

[Original problem](https://codeforces.com/problemset/problem/133/A) · [C++ solution](../../solutions/codeforces/strings/133A_hq9.cpp)

## Try first

Only H, Q, and 9 produce output in this language.

## Reasoning

Only H, Q, and 9 produce output in this language. Searching for any of those characters is necessary and sufficient; the plus instruction changes state without printing.

## Cost

- Time: **O(n)**.
- Extra space: **O(n)**.

## C++ takeaway

Keep the state variables named after the quantities in the invariant. Use standard C++17 containers and check the stated integer bounds.

## Watch for

Lowercase h and q are not the uppercase output instructions.

## Explain it back
