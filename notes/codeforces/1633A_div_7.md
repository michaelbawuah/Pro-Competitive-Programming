# Div. 7

[Original problem](https://codeforces.com/problemset/problem/1633/A) · [C++ solution](../../solutions/codeforces/constructive/1633A_div_7.cpp)

## Try first

Keep a divisible number unchanged.

## Reasoning

Keep a divisible number unchanged. Otherwise, the ten choices for its final digit form ten consecutive numbers, which necessarily contain a multiple of seven; changing one digit is then both sufficient and minimal.

## Cost

- Time: **O(1) per case**.
- Extra space: **O(1)**.

## C++ takeaway

Keep the state variables named after the quantities in the invariant. Use standard C++17 containers and check the stated integer bounds.

## Watch for

Follow the exact input and output formats; check the smallest allowed input.

## Explain it back

State the invariant without looking at the code. Give one input that breaks the most tempting incorrect approach, then add it to the tests.
