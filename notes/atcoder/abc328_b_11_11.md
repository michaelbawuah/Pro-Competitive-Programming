## Try first

Enumerate all valid dates and concatenate the decimal month and day without leading zeros.

## Reasoning

Enumerate all valid dates and concatenate the decimal month and day without leading zeros. A date qualifies exactly when every character equals the first character.

## Cost

- Time: **O(total days * digit count)**.
- Extra space: **O(1)**.

## C++ takeaway

std::string provides zero-based character access, while size() returns an unsigned count. Guard neighbor indices and use the string length when scanning its characters.

## Watch for

Preserve letter case and exact symbols; a character index and its one-based reported position differ by one.
