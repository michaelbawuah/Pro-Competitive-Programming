## Try first

Build only numbers using 3, 5, and 7.

## Reasoning

Build only numbers using 3, 5, and 7. A three-bit mask records which digits have appeared; count a node exactly when all three bits are present and its value does not exceed N.

## Cost

- Time: **O(3^digits(N))**.
- Extra space: **O(digits(N))**.

## C++ takeaway

A generic lambda can recurse by receiving itself as an argument. Keep its return type explicit when deduction would otherwise depend on a recursive call.

## Watch for

Follow the exact input and output formats; check the smallest allowed input.
